# QuickExp Mod

QuickExp is a lightweight Minecraft mod that allows players to rapidly throw experience bottles by holding the right mouse button (RMB).
Works in both main and off-hand. To prevent server bans for using QuickExp, 
the mod sends an Opt-Out Packet when joining a server. If the server's anti-cheat 
software doesn't want the mod to work, it can request that QuickExp be disabled 
**on this server only**.
